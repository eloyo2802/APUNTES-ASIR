# Instrucciones de Configuración de GitHub

1. Abre el script delconfigGitHub.sh para borra los datos actuales de tu ordenador sobre tu cuenta de github.
2. Abre confGitHub.sh para configurar todo (clonar repositorio e instaurar credenciales).
3. Introduce el link de tu Repositorio de GitHub dentro de las "" de la línea 7 de los scripts gitpull.sh y gitpush.sh
